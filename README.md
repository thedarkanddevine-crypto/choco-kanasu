# Choco Kanasu — Full-Stack 3D Website

A premium chocolate brand website for Choco Kanasu, with a real Express + SQLite backend, product inventory, orders, reviews and admin dashboard.

## Run locally

1. Install Node.js 18+.
2. Open this project folder in a terminal.
3. Run:

```bash
npm install
npm start
```

4. Open:
   - Customer site: http://localhost:3000
   - Admin dashboard: http://localhost:3000/admin.html

## Important before production

- Add real product prices in the admin dashboard.
- Add real customer reviews only after obtaining permission/confirmation.
- Add proper admin authentication before public deployment.
- Configure a production database and secure environment variables.
- Integrate and verify a real payment gateway server-side if online payments are enabled.
- Replace the demo order/WhatsApp flow with the business's final delivery and payment policies.
